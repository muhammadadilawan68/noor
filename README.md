# Noor — Duas & Dhikr

Daily duas and dhikr, sorted by act (after salah, morning/evening, sleep…) and by need, with the Arabic, English/Urdu meaning, the reward, and a reference for each one. Includes a daily checklist, tasbeeh counter, a ruqyah session and a knowledge section.

**Open:** https://muhammadadilawan68.github.io/noor/

Works fully offline after the first visit:
- **iPhone:** open the link in Safari → Share → Add to Home Screen.
- **Android:** open the link in Chrome → ⋮ → Add to Home screen / Install app.

Then open Noor once from the new icon while online. Ticks are saved only on your own phone.
